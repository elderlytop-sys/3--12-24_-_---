## Как пересоздать базу
Требуется Python 3. Запустите из корневой папки репозитория:

```bash
python import_data.py
```

Скрипт пересоздаёт `02_individual/repair_service.db`, создаёт таблицы, загружает CSV и добавляет индексы.

## Проверка запросов

### Как смотреть

1. Распакуйте архив целиком.
2. Откройте нужную папку по таблице выше. `otchet.md` удобно читать в VS Code: Ctrl+Shift+V.
3. Базу `practice.db` откройте в DB Browser for SQLite. Она уже заполнена.
4. Для повторения работ 04, 06, 09, 10, 12, 13 создайте **новую пустую базу**, выполните `01_setup.sql`, затем `02_tasks.sql`. Эти скрипты демонстрационные и не предназначены для повторного запуска поверх готовой базы. Для SELECT-запросов можно использовать готовую базу; ALTER/CREATE повторять только в новой.
5. Для работы 07 запустите `python import_csv.py`, для 08 — `python run.py` из соответствующей папки. Скрипты используют только стандартную библиотеку Python и пересоздают только свою practice.db.
6. `13_Индексы/benchmark.py` повторяет замер скорости на 100 000 строках; измеренные значения зависят от компьютера.
7. `python verify_practice.py` проверяет готовые базы и воспроизводит SQL в памяти, не меняя сохранённые данные.

Скрипты реально выполнены в SQLite через Python. Импорт через GUI DB Browser и открытие draw.io в этой среде не выполнялись; в отчётах приведены шаги для воспроизведения. Новые снимки интерфейса не имитируются. Исходная папка `02_individual/` сохранена без изменений.
